# Marketing playbooks

Selected playbooks from [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
(MIT License, see LICENSE), copied unchanged at commit `1f83744`. The marketing assistant in
**Admin → Marketing** gives the relevant ones to Claude for each task, after FinCoursa's own rules
(src/lib/marketing/assistant.ts), which take priority over anything here.

To update: copy the newer files over these, read the changes, then run
`node scripts/build-marketing-playbooks.mjs` to regenerate src/lib/marketing/playbooks.generated.ts.
